# Box3DUnreal

**Box3DUnreal** is a lightweight Unreal Engine plugin that integrates **Box3D** into Unreal Engine 5.

The goal of this project is to provide a clean and straightforward integration of Box3D, making it easy to experiment with or build gameplay systems using one of the most widely used open-source physics engines.

> 🚧 **Early Development**  
> The current focus is integrating Box3D into Unreal Engine. Additional features, documentation, and examples will be added over time.

## Features

* Box3D integrated into Unreal Engine
* Clean Unreal Engine plugin structure
* C++ API
* Compatible with Unreal Engine 5.x

More features will be added as the project evolves.

## Why Box3D?

Box3D, created by **Erin Catto**, is a lightweight and robust physics engine that has been used in countless games and applications. This plugin aims to make Box3D easily accessible from Unreal Engine for developers interested in using it alongside UE's existing systems.

## Installation

Clone the repository into your project's `Plugins` directory:

```text
<Project>/Plugins/Box3DUnreal
```

Generate project files and build your project.
